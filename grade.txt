RUBRIC BREAKDOWN & DETAILED EVALUATION
------------------------------------------------------------------------

1. Grammar and Resulting AST: 1.5 / 1.5
   - Expressions and Precedence: Complete. `expression` (+, -) and `term` (*, /, %) implemented using `chainl1` for left-associativity. Multiplicative operators bind tighter than additive ones. `factor` correctly handles unary plus (dropped) and unary minus (`UMinus`). Parenthesized expressions supported.
   - Identifiers: Complete. Defined as `[a-zA-Z][a-zA-Z0-9_]*` with explicit rejection of reserved keywords (`if`, `else`, `while`). Keyword tokens match on word boundaries (`\b`), correctly allowing identifiers like `iffy` or `whiley`.
   - Statements & Case Classes: Complete. Well-structured `enum Expr` and `enum Statement` deriving `CanEqual` in `src/main/scala/ast.scala`. Supports `ExprStatement`, `Assign(Variable, Expr)`, `Cond(Expr, Block, Option[Block])`, `Loop(Expr, Block)`, and `Block(List[Statement])`.

2. Parser: 1.5 / 1.5
   - Required Grammar Productions: Implemented in `src/main/scala/MiniJSParser.scala`. Covers expressions, terms, factors, assignments, conditionals, while loops, and blocks.
   - Top-Level repl Production: `def repl: Parser[List[Statement]] = rep(statement)` with `parse(input)` using `parseAll(repl, input)`. Handles zero or more statements as well as empty programs.
   - Valid and Invalid Syntax: Accurately parses all specification examples. Rejects invalid syntax (tested extensively with 33 distinct invalid syntax cases, including missing semicolons, malformed control structures, reserved keyword misuse, and integer overflow).

3. toJSON: 1.0 / 1.0
   - Implemented in `src/main/scala/behaviors.scala` (`toJson` functions).
   - Generates nested JSON structures using json4s (`JObject`, `JArray`, `JInt`, `JString`).
   - Supports all AST constructs: numbers as integer values, variables/unary minus as single-key objects, binary operators as arrays of operands, assignments with `left`/`right`, conditionals with `guard`/`then` and optional `else`, loops with `guard`/`body`, and blocks/programs as arrays.

4. Unparser / Pretty Printer: 1.0 / 1.0
   - Implemented in `src/main/scala/behaviors.scala` (`unparse` functions).
   - Expressions converted to infix notation with minimal parentheses based on operator precedence and left-associativity.
   - Each statement appears on a separate line terminated with a semicolon.
   - Indentation: Two spaces per nesting level (`"  " * depth`).
   - Proper formatting of `if` / `else` and `while` loops with braces.
